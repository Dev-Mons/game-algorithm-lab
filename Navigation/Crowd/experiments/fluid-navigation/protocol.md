# 최소 장(field) 비교 실험 — 실행 전 고정한 조건

작성: 2026-09-20. 제품 solver와 독립된 수치 실험이며, PBF/DFSPH/APIC 구현 비교나
개별 원형 에이전트의 이동 검증이 아니다. 목적은 내부 균일화와 외부 확산의 구분이다.

- 동일한 40d × 24d 영역, [8d,32d] × [6d,18d] 사각 지지영역에 점유율 0.72.
- 중심 (20d,12d), 반경 2d의 원형 공동. d는 기준 객체 지름을 나타내는 길이 단위.
- dt=1/60, 8초, 기본 h=0.5d, 추가 h=1d/0.25d. 무작위 요소 없음.
- 공통 평행이동 속도를 뺀 좌표계. 기본 상대속도 0. 벽·접촉·경로 선택 없음.
- A: 용량 상한 0.82만 있는 압력 모델의 정확한 정지 해(p=0). 수치 pressure solver 아님.
- B: 전 영역 보존적 확산 q=-0.6 grad(phi). 군중 외부도 동일하게 취급.
- C: 같은 확산이나 초기 지지영역 경계에서 q·n=0. 알려진 내부 마스크의 이상적 상한.
- B/C는 명시적 finite-volume 5점 stencil. dt*k/h²<=1/4. 프레임별 질량 보존.

사전 판단 기준:

1. 모든 경우 상대 질량 오차 <=1e-10, phi 범위 [-1e-12,0.72+1e-12].
2. A의 초기 공동 deficit 회복률 0 (부호 없는 압력의 반례 확인).
3. C의 8초 원래 공동 평균 deficit 회복률 >=50%, 외부 누출 <=1e-10.
4. B의 외부 질량 비율 >5%이면 무분별한 밀도 확산의 자유표면 부작용 확인.
5. h=0.25d와 0.5d의 C 회복률 차이 <=5 percentage points.

기준을 실패 후 수정하지 않는다. 이 실험에서 마스크는 정답을 제공하므로
자유표면 인식, 원형 packing, 속도 상한, 실제 공동 회복 속도, 군중 전체의 성능은
입증하지 못한다. 밀도장 색칠은 측정 시각화일 뿐 제품 틈을 가리는 렌더링 제안이 아니다.
