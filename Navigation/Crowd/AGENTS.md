# Crowd 문서 읽기

- 먼저 README의 문서 길잡이를 보고, 작업에 해당하는 문서와 코드만 읽는다. docs 전체를 일괄 로드하지 않는다.
- 현재 구조·알고리즘은 `docs/architecture.md`, 이식은 `docs/native-porting.md`, 개선·검증은 `docs/development.md`가 담당한다.
- `baselines`, `docs/research`, `docs/measurements`, fixture는 필요한 개별 자료만 읽는다. 과거 수치와 소스 manifest를 현재 계약으로 취급하지 않는다.
- 개발 이력은 Git에서 확인한다. 진행·완료 보고서를 docs에 추가하거나 기존 문서 끝에 누적하지 않는다.
- 계약이 바뀌면 담당 문서 한 곳과 참조만 갱신한다. 문서 정리에서 fixture·baseline·실행용 재생 자료는 보존한다.
