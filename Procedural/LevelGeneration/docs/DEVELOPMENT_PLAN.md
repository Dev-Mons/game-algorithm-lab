# 개발 범위와 순서

대상은 `Procedural/LevelGeneration`입니다. GitHub #16 및 하위 #17~#27의 현재 본문·댓글을 기준으로 구현합니다. 다른 실험 프로젝트의 명령이나 불변식을 적용하지 않습니다.

순서: #17 계약 → #26 실행/Viewer → #18 공간/접근 → #22 수직/외벽 → #27 편집/Inspector → #19 차량 동선 → #20 공통 입구 → #21 구획/유용성 → #23 에셋/접합 → #24 문맥 시설 → #25 캐시/교차 회귀/성능.

형식 검증에 필요한 banded 스타일 schema/validator만 #17에서 먼저 도입하고 수직 알고리즘은 #22에서 구현했습니다. 각 기능은 자체 실행 슬롯과 Viewer 연결을 포함합니다. 기존 형식·중앙 입구·고정 수직 구간·셀별 시설/조명 방식의 재현 경로는 유지하지 않습니다.

결정론, 실제 충돌 안전성, 입력/계획 분리, 현재 저장·복원·Undo/Redo를 보존합니다. 개방형 주차 건물과 지상 주차 영역의 용도 구분을 유지합니다.

집중 인수 통과 후 다음 단계로 진행하며 최종 검증은 `npm run verify`, `npm run test:e2e`, #25의 application-cold / warm-repeat / 실제 첫 road-add·road-remove·area-remove입니다. 검증이 완료되기 전에는 구현 계획이나 일부 성공만으로 완료 처리하지 않습니다.

현재 상태와 확인된 수치는 [구현 기록](ENVIRONMENT_IMPLEMENTATION.md)에 있습니다.
