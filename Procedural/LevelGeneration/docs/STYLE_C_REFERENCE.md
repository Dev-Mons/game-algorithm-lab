# C · 수평 창 띠 콘크리트 건물

사용자가 제공한 두 이미지를 기준으로 C(`urban-shop`)의 기본 메쉬를 수정했다. 첫 이미지는 단차가 있는 매스와 높은 개구부·지지 기둥을, 두 번째 이미지는 정면의 반복 비례와 후퇴한 옥탑을 읽는 기준이다. 두 이미지 모두 일부가 잘려 있으며 실제 치수와 보이지 않는 면은 제공되지 않았다. 아래 셀 비례는 이미지에서 추정한 제작값이다.

| 요소 | 이미지에서 읽은 특징 | 구현 |
|---|---|---|
| 외벽 | 따뜻한 백색 콘크리트, 넓고 평평한 띠 | C 전용 콘크리트 재질과 돌출 단면 |
| 창 | 낮고 짙은 회색의 수평 연속창, 가는 수직 이음 | 상부 층마다 높이 7/16셀 창; 기존 2층 통유리 프레임 제거 |
| 모서리 | 사선으로 꺾이는 콘크리트 띠 | 실제 볼록 모서리의 돌출 외장만 45도로 절삭하는 고정 프로토타입 |
| 기단 | 넓은 무창 벽과 지면 가까운 출입·유리 면 | 최대 2층 기단; 첫 층 1셀 유리와 바로 위 0.5셀 유리가 연결된 1.5층 창; 모서리 기둥과 검증된 출입구 유지 |
| 상부 | 후퇴한 작은 옥탑, 낮은 솔리드 난간, 어두운 옥상 | 지붕·테라스 전용 회색 재질과 3.25/16셀 높이 난간 |
| 큰 개구부 | 상부 매스를 받치는 긴 백색 기둥 | 개구부를 가진 입력 부피와 기존 지지 기둥 해석, C 전용 색상 |

## 저층과 고층

- **C · 저층 수평 띠와 옥탑**: 본체 10×4×6셀, 옥탑 5×2×3셀. 넓은 기단, 짧은 수평창 반복과 테라스 비중을 비교하는 저층 파생형이다. 첨부 이미지 전체 건물을 저층이라고 단정한 것은 아니다.
- **C · 고층 수평 띠와 옥탑**: 본체 10×10×6셀, 옥탑 5×3×3셀. 두 번째 이미지의 기단–반복 창–후퇴한 상부 구성을 비교한다.
- **C · 계단형 매스와 높은 개구부**: 11×13×6셀 범위. 첫 번째 이미지의 낮은 날개, 높은 본체, 상부 연결부와 개방된 기둥 구간을 비교한다.

높이가 바뀌어도 동일한 수직 프로그램과 외벽 선택 경로를 사용한다. 높이 1–32셀 생성 검사가 적용되며, 좁거나 오목한 건물에도 같은 패턴을 사용한다. 큰 개구부와 후퇴는 편집 가능한 원본 Grid에 속하고, 테마 변경이 사용자의 부피를 임의로 바꾸지 않는다.

원본 셀 점유와 면 소유를 유지하기 위해 사선 처리는 돌출 외장 범위에 한정한다. 원본 부피 전체를 둥글게 깎는 모델은 아니다. 첫 이미지의 외부 사다리·배선 및 사진의 조명/표면 오염은 이번 공통 외벽 메쉬에 포함하지 않는다.

## 호환성과 확인

카탈로그 8에 `streamline-c` 전용 에셋을 추가했다. 카탈로그 2–7은 이전 정의를 검증한 뒤 읽으며 저장된 C 프레임 디자인을 보존한다. 기존 건물을 새 C로 바꾸려면 건물 테마 C를 다시 선택한다. A/B/D/E의 기본 디자인은 유지한다.

`npm run verify`는 타입·단위/행동 검사·빌드, `npm run test:e2e`는 실제 브라우저 검사를 수행한다. `e2e/style-c-reference.spec.ts`는 같은 부피의 변경 전/후 화면과 등각 화면, 편집 가능한 JSON을 `artifacts/style-c-reference/`에 만든다. 모서리 위치, 메쉬 범위, 면 소유, 결정성, JSON 왕복과 이전 문서 호환성을 함께 검사한다.

## 모서리 일관성 수정

기존에는 `pier`에만 사선 에셋이 있었고, 길이 3셀 이상의 외벽 끝에서만 `pier`를 선택했다. 따라서 1–2셀 반환벽과 일반 창/벽 모듈에서는 같은 볼록 모서리 양쪽에 사선과 직각이 섞였다. 별도 cap/belt 마감도 C에 이미 있는 콘크리트 띠 위에 겹쳐 층 경계에서 돌출되었다.

모든 C 창·벽·출입구에 좌/우/양쪽 사선 변형을 제공한다. 동일 셀의 노출된 수직 면을 기준으로 선택하므로 벽 길이, 층 역할, 반복 패턴에 의존하지 않는다. 볼록 외곽은 양쪽 면에 동일한 사선 평면을 사용하며, 유리 끝과 금속 이음도 이 평면을 넘지 않는다. 오목한 안쪽 모서리는 직각을 유지한다. 지지 기둥은 기존 구조 단면을 유지한다.

C는 원래 외장 띠와 옥상 난간에 마감 단면을 포함하므로 별도 cap/belt를 다시 덧붙이지 않는다. 다른 테마의 외부 마감 계획에는 영향을 주지 않는다. 카탈로그 9에서 누락됐던 모서리 변형을 추가했고, 카탈로그 8 문서도 저장된 부피·테마를 유지하며 새 변형을 사용할 수 있다.

1/2/3셀 반환벽, 단차, 기단/반복층/옥상 전환, 네 방향 볼록 모서리, 오목 모서리, 솔리드 벽, 기존 카탈로그 8 저장 파일을 회귀 검사한다. `artifacts/style-c-reference/corners-closeup.png`는 짧은 반환벽과 단차를 확대해 확인하는 실제 렌더다.

## 1.5층 높이의 저층부 창

하부 유리 패널은 높이 1셀(로컬 V -8~8/16), 위쪽 패널은 높이 0.5셀(V -8~0/16)이다. 두 면의 경계에 콘크리트 띠를 넣지 않아 전체 1.5셀 높이의 창으로 연결되고, 얇은 금속 가로 이음으로 구분한다. 모서리의 솔리드 기둥, 상부 일반층 창 띠, 실제 출입구는 유지한다.

높이 2셀 건물도 두 셀을 저층부로 배정해 같은 구성을 사용한다. 1셀짜리 건물이나 위쪽 벽이 없는 단차 끝에서는 창을 자체 지붕 높이 안에 두고 2/16셀의 상부 벽체를 남긴다. 2/3/8셀 높이에서 실제 유리 메쉬의 높이와 접합부 광선 검사를 수행하고, 1셀 지붕·기둥 및 브라우저 렌더도 확인한다. 확인 화면은 `artifacts/style-c-reference/shopfront-8.png`와 `shopfront-2.png`이다.
