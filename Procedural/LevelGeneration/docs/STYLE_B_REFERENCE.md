# B: 브론즈 커튼월 오피스

사용자 제공 사진을 기준으로 B 전용 메쉬와 재질을 제작했다. 회갈색 브론즈 유리, 가는 창 격자, 두 개의 굵은 밝은 수평 벨트, 어두운 평지붕과 연속 난간이 핵심이다.

- 중간층 창 하부의 2.25/16셀은 불투명 회색 벽 패널이다. 유리나 금속 스팬드럴로 덮지 않는다.
- 수평 벨트와 모서리는 평평하게 연결한다. B는 통합 마감을 사용해 별도 돌출 트림을 붙이지 않고, 금속 격자와 출입구를 포함한 외장 돌출은 최대 0.375/16셀이다.
- 굵은 수평 벨트는 높이 1셀 전체가 흰색 벽이다. 해당 타일에는 유리나 반 칸 창을 남기지 않는다. 중간층 창 아래의 얇은 회색 패널은 그대로 유지한다.
- 실제 볼록 모서리 타일의 바깥 끝에는 폭 1/16셀 흰색 기둥을 둔다. 좌우 끝을 구분하고, 폭 1셀 벽에는 양쪽 끝에 적용한다. 일반 창 사이와 오목 모서리에는 기둥을 반복하지 않는다.
- 난간은 옥상 경계에서 4/16셀 높이로 올리고 각 면의 전체 폭을 이어 둘레를 감싼다.
- 흰 벨트는 저층부의 끝과 상층부의 시작에만 배치한다. 그 사이의 일반층은 유리 커튼월을 이어 간다.
- B의 지붕은 `roofAsset`에 선언한 고정 수평 에셋을 사용한다. `roof` 역할과 `PY` 방향만 허용하고, 외벽·테라스·기둥 마감을 대체하지 않는다.
- 첫 실제 렌더와 사진을 비교한 뒤 유리의 밝기·채도를 조정했다. 평지붕의 자기 그림자 줄무늬를 줄이기 위해 작은 그림자 깊이 bias를 적용하고 A도 다시 확인한다.
- A·C·D·E의 메쉬, 스타일 및 재질 정의는 유지한다. 출입문 배치는 전 스타일에 공통 적용한다. 도로 연결이 없어도 비어 있는 1층 지지 공간에 기본 문을 하나 두며, 도로 경로는 검증된 경우에만 기록한다. 기둥과 공중에 뜬 구조물, 출입 공간이 막힌 면에는 문을 강제로 배치하지 않는다.

프로토타입의 **시작 형태 → B · 브론즈 커튼월 오피스**로 12×10×9셀의 편집 가능한 예제를 불러온다. 입면·사선·상부 비교 화면과 `B-reference.json`은 `artifacts/style-b-reference/`에 생성된다. 사진의 작은 옥상 장비와 주변 건물은 포함하지 않았다.

카탈로그 7에 B 에셋을 추가했다. 기존 카탈로그 2~6은 원래 메타데이터를 검증한 뒤 로드하고 저장된 사용자 스타일은 보존한다. 예전 B 파일에 새 외형을 적용하려면 개별 테마 B를 재선택하거나 전역 스타일을 다른 항목으로 바꾼 뒤 B를 선택한다.

카탈로그 10에는 B 모서리 전용 변형을 추가했다. 모양이 같은 변형은 공유하며 카탈로그 9 이하 문서는 기존 타일 목록을 검증한 뒤 업그레이드한다. 저장된 건물 형태와 사용자 스타일 설정은 보존한다.

검증: `npm run verify`, B/A 참고 예제·건축 스타일·옥상 관련 브라우저 회귀. 새로운 검사는 B의 외벽/지붕 면 소유권, 다른 스타일과의 분리, 이전 B 파일의 생성 결과 보존을 확인한다.
