# Blender 도시 참조: A–C

참조는 작업 당시 열려 있던 `CityRenderLab` / `CityDistrict` 장면이다.
원본: `E:\GodotProjects\tiny-dead\levels\city_render_lab\source\city_district.blend`.
전체 도시와 Tower05 확대 뷰 및 재질 정보를 확인했다. Blender 원본 모델은 수정하지 않았다.

선택 가능한 건축 스타일과 개별 건물 테마는 **A, B, C**다.
사용자 요청으로 D 이후의 컨셉, 전용 에셋 및 예제를 제거했다.

|컨셉|특징|
|---|---|
|A|기존 수평 리본 외벽 + 어두운 방수 시트 지붕|
|B|브론즈 창살·어두운 유리 + 기존 흰 벨트|
|C|기존 콘크리트 연속창 + 방수 시트 지붕|

**시작 형태 → A~C · 도시 컨셉**에서 도로, 옥탑과 옥상 설비를 포함한 예제를 불러온다.
설비는 편집 가능한 오브젝트 입력이다. 스타일만 바꾸면 도로나 설비가 자동 추가되지 않는다.
점선 차선·횡단보도·정지선·경계 띠는 공통 도로 표현이다.
난간은 최상단 외벽이 소유하고, 지붕은 기존 지지면을 유지한다.

현재 문서는 schema 6 / catalog 13이다. 이전 A–C 문서는 원래 카탈로그 메타데이터를 검증하고
부피·컨셉·배치 anchor를 유지한다. 삭제된 커스텀 설정은 구버전 이관 시 버린다. catalog 11에 포함되던 폐기 컨셉의 타일 메타데이터는
정확히 일치하는 경우에만 제거하며, 해당 모델을 런타임 에셋으로 등록하지 않는다.
삭제한 컨셉을 사용하는 문서는 지원하지 않는다.

공통 다층 프레임·공간 생성 기능은 기존 사용자 정의 스타일과 알고리즘 검증을 위해 유지한다.
