## 방법과 제한

확인일은 2026-09-25이며 15개 모두 접근 상태는 **재생 가능 / 실제 프레임 표본 확인**이다. 원본 Shorts 주소의 ID를 유지해 YouTube 일반 플레이어로 재생했다. 로그인된 브라우저의 통상 재생 경로를 사용했고 제한 우회·별도 동영상 다운로드는 하지 않았다. 처음 보고된 V01–V03의 일반 웹 fetch 실패는 전달받은 이력이며 이번 재생 결과와 분리한다.

표의 시점은 초 단위로 반올림했다. 정확한 플레이어 `currentTime`, 길이, JPEG 파일은 capture-log에 있다. 영상 일시정지와 숫자키 탐색 뒤 실제 영상 영역을 캡처했다. 시각적 판독은 약 0.1초 수준으로 해석하며 인코딩 프레임 번호의 정밀 동기화 증거로 사용하지 않는다. 재생 중 찍힌 초기 V02의 3개 캡처는 제외했고, 잘린 초기 캡처는 같은 시점의 정상 캡처로 교체했다.

주황색 테두리·사각형·화살표는 **영상 안에서 보이는 조작 단서**다. 분석자가 누른 YouTube 재생 키와 원본 제작자가 사용한 편집 키는 서로 다르다. 키보드 표시나 클릭 로그가 없는 곳에서 “우클릭 삭제”, “E 키 추가” 같은 조작법은 추정하지 않는다. 화면의 연기·입자·흔들림·회전 중간 형상을 최종 geometry로 해석하지 않는다. 제목의 병원/몰/아파트 용도도 내부 프로그램 규칙의 증거가 아니다.

## 이번 근거로 확인하지 못한 공통 조건

Undo/Redo, 저장 복원, 동일 seed 재실행, 동일 최종 입력을 다른 순서로 만든 비교, 음수 좌표, 비다양체, 예산 초과, 지지 삭제, 통로 폐쇄, 다른 시설과 충돌하는 배치, 캐시 적중·미적중은 영상에서 검증하지 않았다. 이후의 결정론·실패·보존 요구는 현재 프로젝트 계약과 제안 설계에 근거한다. 추가 영상 파일을 요구할 접근 장애는 없지만, 원본과 동일한 숨은 동작까지 맞추려면 원본의 입력 파일 또는 편집 로그를 동반한 위 조건의 연속 녹화가 필요하다.
