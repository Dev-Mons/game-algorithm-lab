# 미확정 가설, 교차 검증, 구분 실험

[관찰](OBSERVATIONS.md) · [제안 규칙](RULE_SPEC.md) · [검증](ACCEPTANCE.md)

확신도는 **원본 내부 동작에 대한 가설**의 확신도이며, 화면에 물체가 보였다는 확신도와 다르다. 높음도 원본 소스 확인을 뜻하지 않는다. 다른 영상에 같은 모습이 있다는 사실은 설명의 적용 범위를 늘리지만 숨은 입력·수동 편집·영상 컷이라는 대안을 제거하지 않는다.

## 교차 영상 대응과 한계

| 주제 | 처음 설명한 영상 → 다른 영상 | 교차 확인된 화면 관계 | 모순·예외 또는 미확인 |
|---|---|---|---|
| 외피/부피 | V01 → V04/V12/V15 | 작은 시작 부피, 여러 높이, 창·상단 경계 동반 | V15는 카메라/편집 변화가 커 단조 증가로 설명 불가 |
| 국소 높이 | V04 → V02/V09/V15 | 낮은 날개와 높은 부분이 동시에 상단을 가짐 | 모든 스타일이 같은 높이 비율이라는 증거 없음 |
| 빈 공간/기둥 | V02 → V06/V12/V15 | 돌출부 밑, 연결부 아래, 기둥 사이의 열린 공간 | 가는 사다리형 요소와 두꺼운 점유 기둥을 하나의 자동 지지 규칙으로 묶을 수 없음 |
| 식생 지지 | V03 → V05/V09/V12 | 지상·옥상의 녹지/수목 반복 | V10은 기존 녹지 처리 과정이 가려짐. 지지 삭제 정책의 반례/증거로 사용 불가 |
| 설비 높이 | V05 → V08/V10/V14 | 상자형/탱크/안테나형 옥상 요소 | 단일 높이 임계값으로 셋을 설명하는 근거 없음 |
| 도로와 시설 | V08 → V14/V15 | 교차 표시·도로변 시설·건물 사이 공간 | V08/V15 시작 시 도로가 이미 있음. 도로가 모든 시설을 자동 생성했다는 주장 불가 |
| 주차 | V11 → V13/V12 | 구획·차량·주변 건물과 공존 | 상층 주차와 지상 주차는 연결 조건이 다름. 어느 영상도 proof를 보여주지 않음 |
| 외형 교체 | V06 → V08/V09 | 큰 매스와 외벽 재료/창 표현을 따로 다룰 가능성 | O06 부착물 변화로 “스타일은 재료만 변경” 해석은 부족 |
| 표시 효과 | V07 → V12/V13/V14 | 낮/밤·명암·반사·화면 표현 변화 | 물/날씨가 core 공간 규칙이라는 근거 없음 |

## 잘못 일반화하기 쉬운 주장

- “창이 여러 개 보이므로 내부 방도 생성된다”: 실내 관찰 없음.
- “기둥이 생겼으므로 하중 solver가 있다”: 지지 종류·입력 로그 없음.
- “지상 시점으로 지나갔으므로 navmesh가 있다”: 자유 카메라일 수 있음.
- “주차된 차가 있으므로 운행 가능하다”: 경로·회차·경사로 미관찰.
- “가로등·벤치가 도로 곁이므로 모두 자동 배치다”: 도구 선택/수동 배치 가능.
- “편집 후 예쁜 결과이므로 seed·편집 순서가 안정적이다”: 같은 입력 재실행 비교 없음.
- “공원 위 건물은 식생과 공존한다”: O10의 전후에 식생이 가려져 남았는지 모름.

후속 구현은 미확정 원본 가설을 기다리느라 중단할 필요가 없다. 보존 계약 안에서 가능한 정책을 **제안 설계로 명시**하고, 증거가 부족한 확장은 범위에서 빼거나 기본 동작을 유지한다. 원본과 동일한 숨은 동작이 인수 목표로 추가될 때에는 위 구분 실험을 담은 연속 영상과 입력 파일/로그를 보완 자료로 요청한다.
