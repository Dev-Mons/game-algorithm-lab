# 이번 문서 작업의 검증 기록

검증일: 2026-09-25. 대상은 [진입 문서](../VIDEO_RULE_STUDY.md)와 이 폴더의 분석 문서·프레임 근거다.

## 수행 범위

- 15개 원본 ID와 플레이어 ID, 제목, 길이, 실제 접근 상태를 대응했다. 모두 실제 재생 프레임을 확인했으며 접근 불가능으로 남은 영상은 없다.
- 표본 97장의 파일 존재·실제 JPEG 형식·SHA256·재생 시간 범위를 확인했다. 캡처는 [기록](evidence/capture-log.json)에 일대일 대응한다. 처음 저장할 때의 PNG 확장자를 실제 JPEG 바이트에 맞게 바로잡았으며 재압축하지 않았다.
- Markdown 로컬 링크와 갤러리의 로컬 href/src, 영상별 표본 수·중복·누락을 검사했다.
- O01–O15/H01–H10/R01–R10/C01–C12/T01–T16 정의와 참조를 확인하고, 주요 규칙의 관찰 또는 보존 계약 근거를 검토했다.
- 원본 알고리즘 확정, 실제 보행·차량·하중 증명, 모든 시점 연속 관찰, 새 테스트 통과와 같은 미확인 주장이 없는지 검토했다. 정적인 코드 읽기와 테스트 실행을 구분했다.
- git 변경은 새 docs 분석 자료에 한정됨을 확인했다. 제품 소스·런타임·기존 baseline 변경은 없다.

자동 검사 결과: Markdown 8개, 로컬 링크 110개, 원본 영상 ID 15개, JPEG/갤러리 이미지 97개가 모두 대응했다. 해시는 모두 일치했고 링크 누락·범위 밖 시간·미정의 참조 ID는 없었다. 갤러리의 모든 로컬 href/src도 존재했다. [검사 결과 JSON](validation-results.json)에 수치를 보존했다.

## 실행하지 않은 검사

제품의 전체 타입 검사·단위 테스트·빌드·브라우저 회귀, native export/verify는 실행하지 않았다. 생성 규칙·제품 UI·이식 도구를 변경하지 않은 문서 작업이므로 해당 검사는 이번 변경의 실패 위험을 검증하지 않는다. 후속 구현에서 실행할 항목은 [ACCEPTANCE](ACCEPTANCE.md)에 분리했다.

## 남은 한계

97장은 표본이며 영상 전체를 프레임 단위로 검수하지 않았다. 플레이어 시간은 캡처 직전의 근사 시간이고 원본 편집 이벤트 로그가 아니다. 내부 상태, 숨은 조작, 시뮬레이션·결정론·실패 동작은 [가설 및 실험](HYPOTHESES.md)으로 남는다. 현재 제품을 직접 실행해 신규 결함을 재현한 보고서도 아니다.
