# A: 수평 띠 트윈 타워

사용자가 제공한 건물 사진의 핵심 특징을 A 스타일에 적용했다.

- 밝은 석재 수평 띠와 어두운 청동색 연속 창. 창·기둥·코너 모듈의 슬래브 단면이 이어진다.
- 기존 작은 창틀, 세로 벽기둥, 처마 치형 장식을 A 전용 모듈에서는 사용하지 않는다.
- 프레임 단차는 실제 메쉬이며, 기존 2/16셀 부조 경계를 유지한다.
- B~E의 기존 에셋과 생성 정책은 유지한다.

예제 메뉴의 **A · 수평 띠 트윈 타워**는 32셀 높이의 두 타워, 14셀 높이의 중앙 테라스, 6셀 높이의 하부 진입부, 후퇴한 옥탑을 가진 편집 가능한 입력이다. 스타일 선택은 외벽을 변경하고, 예제 선택은 사진의 건물 형태를 불러온다. **입면** 카메라는 외관 비교용 고정 시점이다.

같은 형태의 변경 전후를 렌더해 비교한 뒤, 첫 결과에서 넓었던 창 띠를 좁히고 중앙 테라스를 낮췄다. 최종 입면·사선·상부 화면은 `artifacts/style-a-reference/`에 있다. `A-reference.json`은 편집기에서 다시 불러올 수 있다.

카탈로그 6은 A 전용 에셋을 추가한다. 카탈로그 2~5 문서는 해당 버전 메타데이터를 검증하여 불러오고, 저장된 사용자 스타일 정의는 보존한다. 예전 A 정의를 유지한 파일에서 새 외형을 쓰려면 개별 건물 테마에서 A를 다시 적용하거나, 전역 스타일을 다른 항목으로 바꾼 뒤 A를 선택한다.

검증: `npm run verify`, 관련 건축 스타일·옥상·카메라·참고 예제 브라우저 회귀. 신규 회귀는 수평 단면의 모듈 이음과 기존 저장 파일의 스타일 보존을 확인한다. 사진의 피사계 심도·후처리는 재현하지 않으며, 건물 형태는 프로젝트의 정육면체 그리드 제약을 따른다.
