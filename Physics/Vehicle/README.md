# Vehicle Physics Lab

차량 물리를 직접 구현하고, 운전·시각화·반복 시험으로 검증하는 독립 프로젝트입니다.
목표는 Toyful Games의 [Making Custom Car Physics in Unity (for Very Very Valet)](https://www.youtube.com/watch?v=CdPYlj5uZeI)에서 설명하는 조절 가능한 레이캐스트 차량입니다.

단일 3D 강체, 네 바퀴 레이캐스트, 바퀴별 세 힘(서스펜션 / 횡방향 접지 / 구동·제동)을 구현했습니다. Unity나 기성 차량 물리 엔진을 사용하지 않습니다. Three.js는 렌더링과 카메라에만 사용하고, 물리 코어는 브라우저 없이 실행됩니다. 기존 `Navigation/Crowd`와 코드·의존성·포트를 분리했습니다.

## 실행

Node.js 22.12 이상을 권장합니다. 이 폴더에서 실행하세요.

```powershell
cd E:\Project\game-algorithm-lab\Physics\Vehicle
npm ci
npm run dev
```

브라우저에서 **http://127.0.0.1:4180/** 을 엽니다. Windows에서는 `run.bat`을 실행해도 됩니다.

## 조작과 실험

| 조작 | 동작 |
| --- | --- |
| W / ↑ | 가속 |
| S / ↓ | 후진 구동력 |
| A·D / ←·→ | 좌우 조향 |
| Space | 브레이크 |
| Shift | 뒤 바퀴 핸드브레이크 |
| P / R | 일시정지 / 초기화 |
| 드래그 / 스크롤 | 카메라 회전 / 확대 |

화면에서 입력칸을 편집 중이면 주행 단축키를 적용하지 않습니다. 자동 시험 중에는 정해진 입력을 사용합니다. **자동 시험 → 직접 운전 → 시험 시작**으로 수동 운전으로 돌아갑니다.

- **미니카 / 밸런스 / 드리프트 / 아이스 / 바운시** 프리셋은 같은 솔버의 파라미터만 변경합니다.
- 슬라이더를 놓거나 키보드로 값을 변경하면 자동으로 차량에 적용하고 초기화합니다. 구동 방식 선택과 JSON 불러오기도 자동 적용합니다. 드래그 중에만 `조절 중`, 적용 후에는 `적용됨`을 표시합니다. **적용값 저장**은 실제 차량 설정을 JSON으로 저장합니다.
- 자유 시험장, 평지, 엇갈린 요철, 점프 경사로를 선택할 수 있습니다.
- 직진 가속, 제동, 원선회, 슬라럼, 1m 낙하, 점프·착지, 요철 통과 자동 시험이 있습니다.
- **입력 재생**은 초기화 이후 기록한 입력으로 같은 초기 상태를 재현합니다. 현재 세션에서 최대 5분의 입력을 보관합니다. 다른 설정을 적용하거나 초기화하면 기록을 지웁니다.
- 속도, 차체 높이, 횡방향 슬립 그래프와 바퀴별 하중을 확인합니다. **현재 결과를 비교 기준으로 +**를 누른 뒤 설정을 변경하고 같은 시험을 실행하면 점선으로 이전 결과를 비교할 수 있습니다.
- **CSV 내보내기**는 20 Hz 측정 데이터를 저장합니다. 최대 5분 분량을 유지합니다. CSV는 측정 결과이며 입력 리플레이 파일은 아닙니다.
- 페이지가 숨겨지면 물리 진행을 멈추고 입력을 해제합니다. 긴 프레임은 한 프레임 최대 12스텝으로 제한하고, 지연 시간을 물리에 큰 dt로 전달하지 않습니다.

URL 예: `/?course=ramp&preset=bounce&paused=true`

### 미니카처럼 빠르게 가속하기

**미니카** 프리셋을 선택하면 600kg, 총 구동력 20,000N, 사륜구동, 저속 마찰 1.8, 목표 최고속도 20m/s(72km/h)가 적용됩니다. 고속에서는 아래의 마찰 곡선으로 접지를 높입니다. 목표 속도 90%(64.8km/h)와 95%(68.4km/h) 도달 시간은 `npm run measure`의 `secondsTo90` / `secondsTo95`로 확인할 수 있습니다. 지면·조향·설정 변경에 따라 달라집니다.

구동력의 단위는 N이며 가속도 자체는 아닙니다. 실제 가속도는 차체에 작용하는 합력 / 질량입니다. 이 모델에서는 속도별 출력 곡선(출발 시 50%), 구동 바퀴 수, 타이어 하중과 마찰, 저항도 영향을 줍니다. 따라서 구동력만 크게 올리면 접지 한계 때문에 가속이 더 늘지 않을 수 있습니다. 목표 최고속도는 출력이 사라지는 속도이며, 속도를 강제로 설정하는 값이 아닙니다. 공기저항 때문에 평지의 최종 속도는 설정값보다 조금 낮습니다.

### 속도별 노면 마찰 곡선

타이어 설정의 그래프에서 점을 위아래로 드래그하거나 아래 슬라이더를 조절합니다. 그래프 점에 포커스를 두고 방향키로 0.05씩 조절할 수도 있습니다. 놓으면 자동 적용·초기화되며, 주행 중 녹색 점과 텍스트로 현재 속도의 실제 마찰 계수를 표시합니다.

| 속도 | 설정 키 | 허용 범위 | 미니카 기본값 |
| --- | --- | --- | --- |
| 0–20 km/h | `friction` | 0.1–2 | 1.8 |
| 40 km/h | `friction40` | 0.1–8 | 2.0 |
| 80 km/h | `friction80` | 0.1–8 | 2.2 |
| 160 km/h 이상 | `friction160` | 0.1–8 | 2.2 |

0과 20km/h 점은 연결되어 저속 전 구간에서 같은 값을 사용합니다. 20km/h를 넘으면 다음 점까지 선형 보간하고, 160km/h를 넘으면 마지막 값을 유지합니다. X축은 목표 최고속도의 비율이 아닌 절대 km/h입니다. 계산에는 차체의 수평 이동 속도 크기를 사용하며, 후진도 같은 곡선을 사용합니다. 공중에서는 계수와 무관하게 타이어 힘이 없습니다.

이 곡선은 횡방향뿐 아니라 가속·제동의 공통 마찰 한계에도 적용됩니다. 높은 값은 차체 하중 이동과 들림·전복을 키울 수 있으므로 미니카 기본 곡선은 급격한 슬라럼에서도 공중 체류 없이 통과한 값으로 설정했습니다. 최대 8은 실험 가능한 상한이며 전복 방지 보정을 의미하지 않습니다.

### 차체 기울기 제어

서스펜션의 **속도별 코너링 기울기** 그래프에서 해당 속도의 기울임 강도를 조절합니다. 낮추면 횡력이 차체를 기울이는 토크가 줄어듭니다. 점 드래그, 포커스 후 방향키, 아래 구간별 슬라이더를 지원하며 조작을 마치면 자동 적용·초기화합니다. 녹색 점과 텍스트는 실제 속도에서 적용되는 강도를 표시합니다.

| 속도 | 설정 키 | 미니카 기본값 |
| --- | --- | --- |
| 0–20 km/h | `rollInfluence` | 1.0 |
| 40 km/h | `rollInfluence40` | 0.6 |
| 80 km/h | `rollInfluence80` | 0.3 |
| 160 km/h 이상 | `rollInfluence160` | 0.2 |

모든 점은 0–1 범위입니다. 0과 20km/h 점은 같은 값으로 연결되고, 나머지 구간은 선형 보간됩니다. 목표 최고속도와 무관한 절대 속도를 사용하며 후진도 동일합니다. 저속에서 기존의 역동적인 움직임을 유지하고 고속에서 기울임 토크를 줄이는 기본 곡선입니다. 높은 마찰을 쓰면 고속 지점부터 0.2–0.3 정도로 조절하세요.

| 설정 | 역할 |
| --- | --- |
| 코너링 기울기 0 | 횡력 작용점을 무게중심 높이에 두어 코너링 롤 토크 억제 |
| 코너링 기울기 0.25 | 횡력의 수직 작용 거리를 원래의 25%로 설정 |
| 코너링 기울기 1 | 기존처럼 바퀴 중심 높이에서 횡력 적용 |
| 스프링 강성 | 서스펜션 압축량과 차체 지지 |
| 댐퍼 감쇠 | 눌리거나 복원되는 움직임의 진동 억제 |

높은 마찰에서 생기는 전복은 스프링·댐퍼만 높여도 해결되지 않을 수 있습니다. 코너링 기울기는 캐주얼 주행감을 위한 힘 작용점 조절이며 실제 질량 중심이나 관성을 변경하지 않습니다. 속도·타이어 마찰 한계를 줄이지 않으며, 구동·제동력의 적용점은 그대로라 직진 가속과 제동 피치도 유지합니다. 횡속도는 변경된 힘 작용점에서 계산합니다.

차체 자세를 강제로 고정하거나 기울기 각도를 잘라내지 않습니다. 노면 경사·요철·충돌·공중 회전에 의한 기울기는 계속 발생합니다. 모든 상황의 전복을 방지하는 장치는 아닙니다.

고속 마찰 점 4인 16초 슬라럼에서는 모든 속도에서 1인 평탄한 기울기 곡선의 최대 롤 약 107.8°가 모든 속도에서 0.25인 곡선에서 약 1.7°로 줄었습니다. 이 고정값 비교와 현재 기본 곡선은 구별해야 합니다. 고속 마찰 3/4/8의 고정값 비교는 `npm run measure`에서 실행하며 `artifacts/roll-control.json`에 저장합니다. 낮은 설정의 직립·공중 체류·접촉 작업 한계를 검사합니다.

이전 JSON에 `rollInfluence` 하나만 있으면 같은 값을 모든 속도 점으로 확장합니다. 이 값도 없으면 전체 1로 변환해 이전 동작을 보존합니다. 새 설정에는 네 기울기 값을 모두 저장하며 CSV의 `roll_influence` 열에는 속도에서 보간한 실제 강도가 기록됩니다.

설정 저장에는 네 계수를 모두 포함합니다. 이전 JSON처럼 `friction` 하나만 있으면 모든 속도에서 그 값을 사용하는 평탄한 곡선으로 변환해 기존 동작을 유지합니다. CSV의 `friction_mu` 열에는 실제 속도에서 보간한 계수를 기록합니다.

### 프리셋과 직접 수정의 일치

프리셋 이름에 따른 가속 보정은 없습니다. 물리 코어는 설정값만 받습니다. 밸런스에서 미니카의 모든 값을 직접 입력하면 `미니카 설정과 일치`를 표시하며 미니카 버튼이 선택됩니다. 브라우저 회귀 테스트에서 두 경로의 첫 2초 직선 가속 텔레메트리가 정확히 일치하는지 검사합니다.

이전에는 직접 수정한 숫자가 별도 적용 버튼을 누르기 전까지 미반영 상태였지만, 이제 조작을 마치면 자동 적용합니다. 질량은 파워트레인에 직접 표시하고, 공기저항과 구름저항은 `조향 · 제동 · 주행 저항`에서 확인할 수 있습니다. 두 저항값은 기존 미니카와 밸런스에서도 같았습니다. 그 외 휠 위치·출력 곡선 등 모델 상수는 모든 프리셋에서 공통으로 사용합니다.

설정 하단의 `현재 적용` 요약은 실제 적용된 질량·구동력·구동 방식·마찰·목표 최고속도를 표시합니다. 일부 숫자만 맞추면 나머지 파라미터가 다를 수 있으므로 완전히 같은 주행 비교에는 모든 설정과 같은 지형·입력·초기 상태를 사용하세요.

프리셋·자동 시험 선택은 차량을 초기화합니다. 시험 실행 시 해당 시험의 지형을 자동 선택합니다. 시험 종료 후 한 스텝 / 계속하기는 종료 상태를 유지하며, 다시 실행하려면 **시험 시작**을 누릅니다.

## 구조

```text
src/physics/math.ts        벡터, 쿼터니언, 곡선 보간
src/physics/body.ts        힘·토크·임펄스, 3D 강체 적분
src/physics/terrain.ts     삼각형 레이캐스트와 시험 지형
src/physics/config.ts      물리 파라미터, 프리셋, 검증
src/physics/vehicle.ts     네 바퀴 힘 계산과 차체 접촉
src/lab/clock.ts           고정 스텝 스케줄러
src/lab/experiments.ts     자동 입력, 텔레메트리, 공통 측정 경로
src/view/scene.ts          Three.js 차량·지형·힘·궤적 표시
src/view/charts.ts         곡선과 실시간 비교 그래프
src/view/speed-curve-editor.ts 마찰·코너링 기울기 공통 그래프 편집기
src/main.ts               조작, 설정, 재생, 파일 저장
tests/unit/               수학·물리·시나리오 회귀
tests/browser/            실제 화면과 조작 회귀
scripts/measure.ts        브라우저 없는 시나리오 측정
```

단위는 m·kg·s이고 오른손 좌표계를 사용합니다. +Y 위, +Z 전방, +X는 운전자 기준 왼쪽입니다. 양의 운전자 조향(D)은 우회전이며 실제 바퀴 Y 회전은 음수입니다. 물리와 화면은 같은 바퀴 각도를 사용합니다.

물리는 120 Hz이며 각 스텝에서 240 Hz 하위 스텝 2회를 고정 실행합니다. 선속도는 반암시적 Euler로 적분하고, 회전은 월드 각운동량과 로컬 대각 관성 텐서·쿼터니언으로 계산합니다. 렌더링은 직전·현재 자세를 보간합니다.

| 18:40–20:41: 속도에 따른 출력 | 저속 50%, 중속 최대, 최고속도에서 0인 곡선 | 가속 시험의 속도 상한 |
| 20:50–21:56: 제동과 구름저항 | 종속도 반대 힘, 정지에 필요한 임펄스 상한 | 제동 후 정지·비의도 역주행 방지 |

추가 안정성 처리: 지면이 차를 당기지 않도록 서스펜션 힘을 0 이상으로 제한합니다. 가속·횡력을 마찰 예산으로 함께 제한하고, 접지 비율은 기준 60 Hz에서 하위 스텝으로 환산합니다.

서스펜션 힘은 차체 부착점에, 구동·제동력은 무게중심 아래의 바퀴 중심에 적용합니다. 횡력은 현재 수평 속도로 기울기 곡선을 보간한 강도에 따라 무게중심 높이와 바퀴 중심 높이 사이에 적용합니다. 각 방향 속도 역시 해당 힘의 작용점에서 계산합니다. 이 높이 차가 코너링의 롤과 가속·제동의 피치를 만들며, 바깥쪽 스프링 압축과 하중이 커집니다. 차체 기울기를 별도 애니메이션으로 덧씌우지 않습니다. 초록 화살표는 실제 서스펜션 힘의 크기와 기울어진 차체 축을 표시하고, 빨강 화살표는 조절된 횡력 작용점에서 시작합니다.

드리프트 프리셋은 뒤 접지 0.25, 미끄러질 때 접지 배율 0.55, 총 구동력 5,500N입니다. 짧은 조향 후에도 계속 회전하던 이전의 낮은 접지·높은 출력 설정을 완화했습니다. 기본 프리셋보다 슬립을 허용하되 조향을 풀면 접지를 회복하도록 조정했습니다. W를 계속 누르고 1초간 최대 조향한 뒤 놓는 키보드 입력도 복원 시험에 포함합니다.

## 검증

```powershell
npm run verify
npx playwright install chromium --only-shell  # 최초 브라우저 준비 시
npm run test:e2e
npm run measure
```

- `verify`: 엄격한 TypeScript 검사, 단위·물리 테스트, 프로덕션 빌드.
- `test:e2e`: 키보드 주행, 정지·단일 스텝, 프리셋/설정, 잘못된 JSON, 자동 시험, CSV, 재생 일치, 지형/카메라, 390px 화면.
- `measure`: 15개 시험·프리셋 조합을 실행하고 `artifacts/measurements.json`에 결과를 저장합니다. 가속 시험에는 목표 속도 90% / 95% 도달 시간이 포함됩니다. 비유한 상태, 15mm 초과 차체 접촉 침투, 스텝당 96회 초과 접촉 샘플 작업이면 실패합니다. 미니카는 90% 도달 1.5초 이내, 95% 도달 1.8초 이내를 검사합니다.
- 추가 조향 후 복원 시험은 12m/s에서 1초간 조향한 뒤 놓습니다. `artifacts/handling.json`에 최대 슬립·누적 회전·롤·좌우 하중 차이를 기록하며, 90° 초과 누적 회전이나 복원 실패를 검출합니다. 좌우 대칭과 네 지형의 공통 평지에서 실제 스프링 하중 이동을 회귀로 검사합니다.
- E2E 스크린샷은 `artifacts/vehicle-desktop.png`, `artifacts/vehicle-mobile.png`에 저장합니다.
- 30/60/144 Hz 렌더링 일정에서 같은 입력을 받은 물리 상태가 정확히 일치하는 회귀 테스트가 있습니다. 서로 다른 JavaScript 엔진·CPU 간 비트 단위 결정론은 보장하지 않습니다.

**제동 결과 비교 주의:** 자동 제동 시험은 정지에서 6초 가속한 후 브레이크를 밟습니다. 아이스는 그 6초 동안 도달하는 속도도 낮으므로 이 시험의 제동거리만으로 노면 마찰을 비교하면 안 됩니다. 단위 테스트는 같은 15m/s 초기 속도에서 아이스의 제동거리가 더 긴지 별도로 확인합니다.

## 범위와 현재 한계

영상 수준의 조절 가능한 아케이드 차량 핵심을 목표로 합니다. 원작의 숨겨진 파라미터나 주행감을 수치적으로 복제했다고 주장하지 않습니다.

- 바퀴는 별도 강체가 아닙니다. 회전은 속도에 맞춘 시각 효과이며 타이어 회전 관성, 실제 휠스핀·ABS, 기어·클러치·차동기어, 정밀 타이어 변형을 시뮬레이션하지 않습니다.
- 차체 접촉은 12개 구형 샘플과 지면/고정 박스에 대한 고정 4회 임펄스·위치 보정입니다. 차체 메시와 완전히 동일한 충돌체, 차량 간 충돌, 범용 CCD는 아닙니다.
- 지형은 위쪽 표면을 가진 단층 시험장입니다. 터널·다층 교량·지형 아래 통과는 지원하지 않습니다. 경사로 가장자리의 수직 측면을 정밀한 메시 충돌로 처리하지 않습니다.
- 서스펜션 레이캐스트는 삼각형 지형만 조회합니다. 뒤쪽 고정 벽은 차체 충돌 시험용이며 바퀴로 올라타는 장애물이 아닙니다. 콘은 시각적 표식입니다.
- 접촉 침투는 솔버 허용오차가 있습니다. 측정에서 작은 잔여 침투를 숨기거나 0으로 반올림해 통과시키지 않습니다.
- 뷰포트는 좁은 화면에서도 배치되지만 수동 운전은 키보드 기준입니다. 모바일에서는 자동 시험과 설정 조절을 사용할 수 있습니다.

차량 느낌을 더 조정할 때는 먼저 같은 자동 시험으로 기준 데이터를 저장한 뒤, 하나의 파라미터를 변경하고 비교하세요. 영상의 동작을 위한 회귀를 유지하면서 타이어 모델이나 충돌체를 확장할 수 있습니다.
